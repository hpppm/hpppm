## 🏥 Senior Design: RevClear — AI Medical Billing Platform

![Status](https://img.shields.io/badge/Status-Live-brightgreen?style=flat-square)
![Commits](https://img.shields.io/badge/Commits-822%2B-blue?style=flat-square)
![HIPAA](https://img.shields.io/badge/HIPAA-Compliant-red?style=flat-square)
![Repo](https://img.shields.io/badge/Repo-Public-brightgreen?style=flat-square&logo=github)

**RevClear** is an AI-assisted medical claims platform I built as my senior capstone at Gannon University, live at **[revclear.tech](https://revclear.tech)**. The source code is publicly available on GitHub. It automates the full clinical billing pipeline: audio recording → SOAP note generation → ICD-10/CPT code matching → EDI 837 claim file.

### Architecture

```
Patient Audio
     |
     v
AssemblyAI (HIPAA BAA, presigned S3 URL, 120s TTL)
     |
     v
AWS S3 (KMS-only upload, blocked public access)
     |
     v
Google Gemini 2.5 Flash (SOAP generation)
  -- fallback --> Groq Llama 3.3-70B
     |
     v
Pinecone Vector DB (ICD-10 + CPT namespace search)
     |
     v
Async Job Pattern (202 + polling, 10-min TTL → prevents 504)
     |
     v
EDI 837 Claim File
     |
     v
Railway Backend (Express + TypeScript) <-- Cloudflare WAF/DNS
     |
     v
Railway Frontend (Next.js 16 App Router)
```

### Key Security Implementations

| Area | Implementation |
|------|---------------|
| PHI Encryption | AES-256-GCM, 12-byte random IV, 128-bit auth tag, `revclear:phi:v1:{iv}:{tag}:{ct}` wire format |
| Auth | AWS Cognito mandatory TOTP MFA, httpOnly JWT cookies, JTI replay protection |
| Audit Logging | HIPAA 45 CFR §164.312(b) — 100+ PHI keys masked, UUIDs scrubbed to `[id]` |
| Data Isolation | Dual-scope: every query enforces `organization_id` AND `clinician_id` |
| Threat Detection | Brute force, SQL/XSS pattern blocking, 404 scanning → 15-min IP block |
| CI/CD Security | GitHub Actions: `npm audit`, `tsc`, Jest, Semgrep SAST on every PR |
| Transcription | AssemblyAI under signed HIPAA BAA; presigned URL deleted immediately post-retrieval |
| Infrastructure | Cloudflare WAF + DDoS; AWS S3 KMS-only policy; RDS SSL enforced + encrypted at rest |

### Usability Design

Built to the Eight Golden Rules of Interface Design (Shneiderman): consistency across all views, shortcuts for power users, informative error messages, error prevention through Zod validation at all boundaries, and clear visual hierarchy via consistent component patterns throughout the dashboard.
